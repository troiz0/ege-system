**EGE.SYSTEM** — веб-платформа полного цикла для системной подготовки к Единому государственному экзамену по актуальным спецификациям КИМ ФИПИ 2026/2027.

Платформа спроектирована в эстетике тактического кибер-HUD (`Neon Lime #D4FF00` на глубоком тёмном фоне `#09090B`). Интерфейс адаптирован как для настольных рабочих станций (двухколоночный сплит-скрин, 1920×1080+), так и для мобильных устройств (PWA-ready, адаптация под мобильную клавиатуру `pb-32`, отсутствие горизонтального скролла, строгие `rounded-none` контуры).

## ⚡ Ключевые возможности

### 1. Боевой Telegram-бот и телеметрия прогресса (`backend/src/services/telegramBot.ts`)
- **Мгновенная привязка через Deep-Link:** генерация токена привязки на сайте (`/profile`) и подключение по ссылке вида `https://t.me/<BOT_USERNAME>?start=link_<TOKEN>`.
- **Авторизация через Telegram (Telegram Login):**
  - Поддержка Telegram Login Widget и быстрой беспарольной авторизации через одноразовые токены.
  - Криптографическая валидация подписи по стандарту Telegram: `HMAC-SHA256(data_check_string, SHA256(bot_token))`.
  - Автоматическая синхронизация профиля и телеметрии.
- **Еженедельные дайджесты и экстренные алерты:**
  - Отправка родителям и ученику еженедельной аналитики (чистые часы учебы, количество решенных задач, освоенные темы, динамика баллов).
  - Срочные предупреждения при проседании результатов КИМ или нарушении дедлайнов.
  - Поддержка интерактивной команды бота `/digest` для запроса свежей сводки в любой момент.
- **Интегрированная система баг-репортов (`/bug`):**
  - Ссылка «Сообщить об ошибке» в футере сайта ведет прямо в бота с диплинком `https://t.me/<BOT_USERNAME>?start=bug`.
  - Пошаговый сбор описания дефекта с поддержкой фото, скриншотов, файлов, голосовых сообщений и логов.
  - Автоматическая пересылка отчета в чат разработчика `TELEGRAM_ADMIN_CHAT_ID` с метаданными пользователя и датой.

### 2. Двухфакторная регистрация и верификация Email OTP (`backend/src/services/emailService.ts`, `backend/src/routes/auth.ts`)
- **Модель временных кодов (`VerificationCode` в Prisma):**
  - 6-значный криптографически безопасный одноразовый код (`Math.floor(100000 + Math.random() * 900000)`).
  - Защищенный `payload` с предварительно захешированным паролем (`bcrypt`, saltRounds = 10), именем и выбранным классом (9, 10 или 11 класс).
  - Срок действия кода: 10 минут (`expiresAt = now + 10m`) с составным индексом `@@index([email, code])`.
  - Антиспам-защита: 60-секундный кулдаун на повторный запрос кода (`/api/auth/register/resend-code`).
- **Служба отправки писем (`emailService.ts`):**
  - Интеграция с SMTP через Nodemailer (`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`).
  - Фирменный темный HTML-шаблон письма в стиле кибер-HUD платформы EGE.SYSTEM с крупным моноширинным кодом и тайм-лимитом.
  - Dev-режим: при отсутствии SMTP-конфигурации код безопасно выводится в терминал разработчика без блокировки регистрации.
- **Двухшаговый HUD-интерфейс регистрации (`AuthModal.tsx` / `RegisterForm.tsx`):**
  - **ШАГ 1:** ввод имени, выбор класса (9, 10, 11), email и пароля с валидацией Zod.
  - **ШАГ 2:** ввод кода подтверждения через **6 независимых цифровых полей** с автоматическим фокусом, обработкой Backspace, навигацией стрелками и мгновенной вставкой из буфера обмена (Paste).
  - Таймер обратного отсчета 60 секунд до повторной отправки и кнопка возврата к редактированию email.
  - Гарантированное сохранение выбранного класса ученика во всех подсистемах (сессия, профиль, сайдбар, PDF-отчеты).

### 3. Единый сектор безопасности и привязка аккаунтов (`/profile`)
- **Консолидированный блок «Безопасность и привязка аккаунтов»:** все способы входа и связи собраны в единый чистый интерфейс:
  - **Email:** статус подтверждения, привязка/смена адреса с двухфакторным подтверждением.
  - **Telegram:** текущий статус привязки, генерация персонального токена, кликабельная ссылка на бота, кнопка быстрого копирования команды `/start link_<TOKEN>`, кнопки мгновенного тестирования еженедельного дайджеста и экстренного алерта.
  - **Google OAuth:** привязка аккаунта Google в один клик.
- **Полное удаление аккаунта (152-ФЗ / GDPR):**
  - Эндпоинт `DELETE /api/profile/account` каскадно и безвозвратно удаляет учетную запись, историю решений, оценки, сканы и токены.
  - Подтверждение через фирменное тактическое модальное окно.

  - Применено для всех критических сценариев: выход из системы, удаление диалогов ИИ-чата, перегенерация плана, удаление уроков, удаление оценок, запуск синхронизации схемы БД и очистка кэша.

### 5. Честная аналитика без фейковых данных (Truthful Empty State)
- **Честный Telegram-бот:** если у пользователя 0 сданных пробников или нет активности за неделю, бот прямо сообщает: `«• Пробники: еще не сдавались»`, `«• Чистых часов подготовки: 0 ч»` без выдуманной дельты и приглашает написать первый пробник в Симуляторе.
- **Предиктор баллов (`analyticsPredictor.ts` / `dashboard.ts`):** возвращает `hasEnoughData: false` и `predictedScore: null`, если сданных КИМ недостаточно для математически достоверного расчета.
- **Виджет прогноза на фронтенде (`ScorePredictorWidget.tsx`):** при отсутствии данных отображает стильный HUD-блок `[ ДАННЫХ НЕДОСТАТОЧНО ДЛЯ РАСЧЕТА ]` с прямой кнопкой `[ НАПИСАТЬ ПЕРВЫЙ ПРОБНИК ]` на Симулятор экзамена.

### 6. Закрытая панель администратора (`/admin`)
- **Строгий контроль доступа (`requireAdmin`):** вход разрешен исключительно доверенным администраторам платформы (`ADMIN_EMAILS`); для остальных пользователей доступ полностью заблокирован (HTTP 403 Forbidden).
- **HUD-метрики командного центра:**
  - Мониторинг ключевых показателей платформы в реальном времени: общее число зарегистрированных пользователей, сданных пробников КИМ, проверенных домашних заданий, закрытых дефицитов и сессий ИИ-репетитора.
  - Живой статус Telegram-бота и время непрерывной работы сервера (Uptime).
- **Управление пользователями и модерация:**
  - Полнотекстовый поиск по пользователям (email, имя, класс, трек, статус).
  - Отображение статуса Telegram-привязки (`chatId`, `@username`).
  - Система блокировок (`POST /api/admin/users/:id/ban` и `unban`) с фиксацией причины бана и автоматической отправкой Telegram-уведомления нарушителю при наличии привязки.

### 7. BATTLEGROUND — PvP Арена (`/arena`, `/pvp`)
- **Матчмейкинг в реальном времени:** интеллектуальная очередь подбора соперников (`POST /api/pvp/queue`) с мгновенным спавном тренировочных соперников при отсутствии живых оппонентов.
- **Дуэль 1 на 1:** раунд 90 секунд, одинаковый синхронный пак из 3 быстрых задач первой части КИМ.
- **Живая телеметрия прогресса:** HUD-индикатор решения задач соперником в реальном времени.
- **Мгновенная фиксация победы:** начисление +30 XP победителю, динамический протокол исхода матча и детальный математический разбор всех задач дуэли.

### 8. EXPERT SIMULATOR — Режим «ЕГЭ-Эксперт» (`/expert-mode`)
- **Критериальная проверка КИМ глазами старшего эксперта ФИПИ:** отлов математических, логических и критериальных ловушек в решениях учеников.
- **3 уровня сложности экспертизы:**
  - `[ УРОВЕНЬ 1: Легкий ]` — элементарная арифметика, описки и потеря знака при переносе.
  - `[ УРОВЕНЬ 2: Средний ]` — критериальные ловушки (деление на ноль, потеря ОДЗ в логарифмах, неверный отбор корней на тригонометрическом круге).
  - `[ УРОВЕНЬ 3: Сложный ]` — логические дыры в параметрах (№18) и теории чисел (№19), некорректная равносильность переходов, пример без оценки.
- **Официальный вердикт ФИПИ:** проверка конкретного шага с ошибкой, критериальное обоснование и начисление наградного XP.

### 9. AI APPEAL RISK CALCULATOR — Калькулятор рисков апелляции (`/appeal-calculator`)
- **Двусторонний нейроаудит (Upside vs Downside):** нейросеть анализирует скан рукописного чистовика и условие задачи сразу с двух сторон:
  1. *Потенциал повышения (Upside):* аргументированные зацепки по критериям К1/К2 для отвоевания +1..+2 первичных баллов.
  2. *Риск понижения (Downside):* выявление скрытых дефектов работы, из-за которых конфликтная комиссия при тотальной перепроверке может снизить балл.
- **Интерактивная HUD-шкала угрозы:** индикатор риска (`[ НИЗКИЙ РИСК: ПОДАВАТЬ ]` vs `[ ОПАСНО: ВЫСОКИЙ РИСК ПОТЕРИ БАЛЛА ]`), тактика поведения на заседании и аргументы со ссылками на методические материалы ФИПИ.
- **HUD CustomSelect:** фирменный селектор дисциплин со стилизованными бейджами и иконками предметов.

### 10. Offline-First Симулятор экзамена (`/exam-pressure`)
- **Полная автономность (IndexedDB):** непрерывное локальное сохранение состояния активного экзамена (`variant`, `answers`, `scans`, таймер `secondsLeft`). Мгновенное восстановление прогресса при перезагрузке страницы (F5) или случайном закрытии вкладки.
- **Индикатор потери сети:** автоматическое обнаружение отключения интернета с аккуратным HUD-индикатором `[ АВТОНОМНЫЙ РЕЖИМ // СЕТЬ ОТСУТСТВУЕТ // ДАННЫЕ В БЕЗОПАСНОСТИ ]`.
- **Локальный ход таймера:** обратный отсчет времени не прерывается в офлайне, результаты безопасно отправляются на сервер при возобновлении связи.

### 11. Интерактивный параметрический графопостроитель в AI-Чате (`/chat`)
- **HUD Canvas Plotter:** рендеринг интерактивных 2D-графиков функций прямо в переписке с ИИ-репетитором при наличии блока ````plotter````.
- **Параметрические исследования:** интерактивный ползунок для параметра $a$ с физическим смещением графиков, динамической координатной сеткой и точками пересечения кривых в реальном времени.

### 12. Стартовый онбординг и экспресс-диагностика (Zero-State Protocol)
- **Персонализированный выбор трека:** выбор направления подготовки (Физмат/IT, Инженерно-технический, Социально-экономический, Гуманитарный) с автоматической калибровкой банка заданий и приоритетов тем.
- **Сохранение онбординга в БД:** флаг завершения первичной настройки сохраняется в SQLite, гарантируя надежность сессий на любых устройствах.
- **Экспресс-срез за 15 минут (`mode=diagnostic`):** стартовый диагностический КИМ из 5 ключевых базовых задач первой части для моментальной инициализации персонального дерева навыков без прохождения 4-часового полного теста.

### 13. Симулятор экзамена под давлением и Pacing-ассистент
- **Спецификация КИМ:** профильная математика строго включает **20 заданий** (13 тестовых, 7 с развернутым решением), максимум **33 первичных балла**.
- **Честный подсчет баллов:** суммарный первичный балл рассчитывается по формуле `totalPrimaryScore = correctPart1Count + part2PrimaryScore` с конвертацией во вторичный балл (0–100) по актуальной шкале ФИПИ.
- **Pacing-ассистент («Тайм-менеджер КИМ»):** динамическая шкала рекомендуемого темпа по части 1 и 2, предупреждающие сигналы за 30 и 10 минут до окончания для своевременного переноса ответов в бланки.

### 14. Сквозная геймификация и Gamification Engine (`backend/src/services/gamificationService.ts`)
- **Математическая модель уровней:** порог перехода на следующий уровень динамически масштабируется по формуле `xpForNextLevel = level * 10` (Уровень 1: 0–10 XP, Уровень 2: 11–25 XP, Уровень 3: 26–50 XP).
- **Тактические HUD-ранги профиля:**
  - `LVL 1–100` — **РЕКРУТ**
  - `LVL 100–1000` — **КУРСАНТ**
  - `LVL 1000–2000` — **СТАЖЁР ВУЗА**
  - `LVL 2000+` — **СТОБАЛЛЬНИК**
- **Изолированный виджет прокачки в Профиле (`/profile`):** отдельный блок `[ ПРОКАЧКА // УРОВЕНЬ И ОПЫТ ]` с крупным бейджем текущего уровня, динамическим рангом, неоновым HUD-прогресс-баром (`#D4FF00`) и счетчиком оставшегося опыта.
- **Сквозное начисление XP по ключевым событиям:**
  - ✅ **Выполнение темы в плане** (`/api/study-plan/:id/complete`): `+50 XP`.
  - ✅ **Блиц-тест тренажера** (`/api/trainer/verify`): `+10 XP` за каждый верный ответ (до `+30 XP` за 3/3).
  - ✅ **Экспресс-тест в Матрице знаний** (`/api/matrix/test/complete`): `+30 XP` со всплывающим HUD-тостом `[ +30 XP // ТЕМА ОСВОЕНА ]`.
  - ✅ **Сдача КИМ в симуляторе экзамена** (`/api/exams/submit`): крупный динамический бонус `primaryScore * 10` (например, 25 первичных баллов = `+250 XP`, максимум до `+330 XP`).
  - ✅ **Победа в PvP Battleground:** `+30 XP` за выигранную дуэль.
  - ✅ **Стрик активности без сбросов:** при непрерывной подготовке от 2 дней начисляется ежедневный бонус первого действия: `+10 XP * текущий_стрик`.

### 15. Бесшовное изучение тем Матрицы знаний в AI-Чате (`/matrix` → `/chat`)
- **Кнопка «Разобрать с ИИ»:** во всех карточках тем кодификатора ФИПИ и дерева навыков доступна кнопка `[ РАЗОБРАТЬ С ИИ ]` со строгой векторной иконкой.
- **Мгновенная инициализация сессии:** клик автоматически переносит ученика в AI-Чат, создавая именованный диалог по теме и мгновенно отправляя структурированный методический промпт.

### 16. Рабочий кабинет учителя и репетитора (`/tutor`)
- **Классы в базе данных:** модели `ClassGroup` и `ClassMember` в SQLite через Prisma для надежного управления учебными группами.
- **Инвайт-коды репетитора:** строгая валидация инвайт-кодов с привязкой ученика к назначенному наставнику.
- **Сдача и проверка домашних работ:** ученики вводят ответы, прикрепляют сканы рукописных чистовиков через выделенный сервис загрузки и отправляют работу на проверку наставнику.
- **Пакетная печать КИМ:** KaTeX-пререндеринг формул в печатную версию и инверсия линий геометрических чертежей (черные контуры на белом фоне) для идеальной печати на бумаге.

### 17. Родительский пульт управления (`PARENT DESK`) и официальный PDF-отчет
- **Честный калиброванный прогноз:** расчет вероятности поступления на основе реальных баллов сданных пробников без искусственных завышающих коэффициентов.
- **Прогноз по триаде предметов:** реалистичный суммарный балл и подбор целевых вузов (МЭИ, МАИ, РТУ МИРЭА, региональные опорные университеты).
- **Экспорт отчета за месяц в PDF (`/api/profile/report-pdf`):** формирование сводного методического документа для родителей и репетитора: динамика баллов, закрытые пробелы, чистое время решения.

### 18. Интеграция с МЭШ и Feature Flags (`/config`)
- **Режим «СТРОГИЙ КИМ ФИПИ»:** возможность изолировать аналитику подготовки от текущих школьных оценок МЭШ.
- **Гранулярные тумблеры:** независимое отключение подмешивания уроков МЭШ в чат, предиктора баллов и адаптации расписания.

## ⚡ Оптимизация производительности

- **SQLite WAL Mode & Transactions:** при запуске Prisma применяются директивы `PRAGMA journal_mode = WAL;` и `PRAGMA synchronous = NORMAL;`. Массовые операции сохранения экзаменов обернуты в атомарные транзакции `prisma.$transaction()`, устраняя блокировки `SQLITE_BUSY: database is locked`.
- **Code-Splitting бандла:** все тяжелые страницы (`ExamPressureSimulatorPage`, `MaterialsPage`, `SchedulePage`, `MeshDiaryPage`, `LandingPage`, `AdminPage`) загружаются динамически через `React.lazy()`. В `vite.config.ts` настроена разбивка библиотек по изолированным чанкам (`vendor-vendor`, `katex-chunk`, `three-chunk`, `icons-chunk`), что уменьшило вес главного бандла `index.js` до ~360 kB (gzip: ~100 kB).

## 🔒 Безопасность и соответствие 152-ФЗ / GDPR

- **Защита персональных данных (152-ФЗ):** токены доступа к электронному дневнику МЭШ не сохраняются в незашифрованном виде. Токен хранится исключительно в зашифрованном виде по алгоритму **AES-256-GCM**.
- **Право на забвение (Full Account Erasure):** эндпоинт `DELETE /api/profile/account` каскадно и безвозвратно удаляет учетную запись и все связанные записи из SQLite.
- **Защита от Indirect Prompt Injection:** текст из загружаемых пользователем документов санируется и изолируется в разметке `<untrusted_attachment context="user_uploaded_document">`. Системный промпт содержит жесткий запрет на выполнение инструкций из файлов пользователя.
- **Защита хранилища пользовательских сканов:** эндпоинт статических файлов `/uploads` защищен middleware авторизации `requireAuth`. Анонимный доступ к решениям и сканам закрыт (HTTP 401).
- **AI Rate-Limiting:** на эндпоинты искусственного интеллекта (`/api/ai`, `/api/fipi-check`, `/api/trainer`) установлен строгий лимит частоты запросов (`30 req/min`). Роуты Telegram-авторизации и polling защищены от ложных 429 блокировок.

## 🚀 Установка и запуск

### Системные требования
- **Node.js:** версия 20+ (LTS)
- **npm:** версия 10+ (поддержка npm workspaces)
- **ОС:** Windows / Linux / macOS
- **База данных:** встроенная SQLite (`backend/prisma/dev.db`), внешняя СУБД не требуется

### 1. Клонирование репозитория
```bash
git clone https://github.com/troiz0/ege-system.git
cd ege-system
```

### 2. Установка зависимостей
```bash
# Устанавливает зависимости для backend и frontend (workspaces)
npm install
```

### 3. Настройка переменных окружения
Создайте файл `backend/.env` на основе примера:
```bash
# Windows
copy backend\.env.example backend\.env

# Linux / macOS
cp backend/.env.example backend/.env
```

Пример параметров в `backend/.env`:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-super-secret-jwt-key-min-32-chars"
ENCRYPTION_KEY="0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
PORT=3001
CLIENT_ORIGIN="http://localhost:3000"

# OpenRouter AI (для обращения к LLM)
OPENROUTER_API_KEY=""

# Telegram Bot
TELEGRAM_BOT_TOKEN=""
TELEGRAM_BOT_USERNAME="ege_system_bot"
TELEGRAM_ADMIN_CHAT_ID=""

# Google OAuth (опционально)
GOOGLE_CLIENT_ID=""

# SMTP для подтверждения почты (опционально, в dev-режиме код выводится в терминал)
SMTP_HOST=""
SMTP_PORT="587"
SMTP_USER=""
SMTP_PASS=""
SMTP_FROM="noreply@ege.system"
```

### 4. Инициализация базы данных
```bash
# Миграции SQLite и генерация Prisma Client
npm run migrate -w backend
npm run prisma:generate -w backend

# Заполнение демонстрационными данными
npm run seed -w backend
```

### 5. Настройка Telegram-бота (опционально)
Если задан токен бота, можно автоматически настроить команды, имя и описание:
```bash
npm run setup-telegram -w backend
```

### 6. Запуск платформы
```bash
# Одновременный запуск Backend (порт 3001) и Frontend (порт 3000)
npm run dev
```

Откройте в браузере: **`http://localhost:3000`**

> **Быстрый демо-вход:** на странице входа нажмите кнопку **«Демо-вход»** — откроется аккаунт `demo@ege-ai.ru` с предзаполненными результатами, расписанием и открытым доступом ко всем модулям.
